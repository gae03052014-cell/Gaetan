📧 Niveau 2 - Envoi réel sans serveur GRATUIT

Tu n'as pas besoin de toucher au code. Tout se règle ici, c'est stocké dans ton navigateur.

Comment obtenir tes clés EmailJS (2 min) :
1. Va sur emailjs.com > Sign Up gratuit
2. Add New Service > Gmail > Connecte ton Gmail > Copie Service ID
3. Email Templates > Create New Template > Mets ce contenu :
To: {{to_email}}
Subject: {{subject}}
Message: {{message}}
From: JARVIS
4. Save > Copie Template ID
5. Account > API Keys > Copie Public Key
❌ Non configuré - envoi via ouverture de ton app mail (mailto)
Une fois configuré : Tu dis "Jarvis envoie un email à test@gmail.com pour dire bonjour" > Je génère le draft > Tu dis "oui envoie" > Ça part vraiment via EmailJS, sans ouvrir Gmail. Limite gratuite : 200 mails/mois.

🚀 Niveau 3 - Backend perso illimité PRO

C'est quoi ?
Au lieu de passer par EmailJS, ton site GitHub Pages appelle ton propre serveur qui envoie le mail via Gmail SMTP. Illimité, gratuit, tu contrôles tout.

Architecture :
GitHub Pages (ton index.html)
↓ fetch POST
Ton API sur Render.com (email_api.py)
↓ SMTP
Gmail → destinataire

Comment le faire (10 min) :
1. Va sur myaccount.google.com/apppasswords > crée mot de passe d'app "JARVIS" > copie les 16 lettres
2. Télécharge ces fichiers :
• real_email.py + email_api.py
3. Crée repo GitHub `jarvis-email-api` avec ces 2 fichiers + `requirements.txt` (fastapi uvicorn python-dotenv)
4. Va sur render.com > New Web Service > connecte ton repo > Build: pip install -r requirements.txt Start: uvicorn email_api:app --host 0.0.0.0 --port 10000
5. Dans Environment > ajoute SMTP_USER=ton gmail et SMTP_PASS=ton mdp d'app
6. Une fois déployé, tu as une URL genre https://jarvis-email-api.onrender.com → colle-la ci-dessous

❌ Pas d'API perso - utilise Niveau 2 ou mailto
Priorité d'envoi : Si API perso renseignée → j'utilise Niveau 3. Sinon si EmailJS configuré → Niveau 2. Sinon → mailto (ouvre ton app mail). Tu n'as jamais besoin de toucher au code, juste ces champs.
